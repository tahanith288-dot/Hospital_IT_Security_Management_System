# Hospital IT Security Management System

A portfolio-ready demo web application for managing hospital IT assets, endpoint security status, and IT support tickets.

## Features
- IT asset inventory
- Endpoint security status
- IT support ticket tracking
- Dashboard statistics
- CSV export
- SQLite database
- Responsive web interface

## Run locally

1. Install Python 3.10+.
2. Open this folder in VS Code.
3. Open the terminal and run:

```bash
pip install -r requirements.txt
python app.py
```

4. Open the address shown in the terminal, usually:
`http://127.0.0.1:5000`

## Portfolio note
This project uses fictional/demo hospital data. Do not enter real patient information or confidential hospital data.
